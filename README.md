# Site Audit

`Site Audit` - веб-приложение для SEO-аудита конкурентоспособности страницы по конкретному поисковому запросу.

Пользователь указывает URL страницы и поисковый запрос. Система получает страницы конкурентов из поисковой выдачи, анализирует целевую страницу и top-N конкурентов, извлекает технические, текстовые, коммерческие и семантические признаки, рассчитывает ML-оценку и формирует рекомендации по улучшению страницы.

Проект ориентирован на инженерную задачу: автоматизировать SEO-аудит, который обычно выполняется вручную, и показать работу распределённых вычислений через очереди задач `Celery` и брокер `Redis`.

## Возможности

- запуск SEO-аудита по URL и поисковому запросу;
- получение конкурентных страниц через локальный `SearXNG`;
- распределённое выполнение стадий аудита через `Celery + Redis`;
- анализ целевой страницы и конкурентов;
- извлечение технических, текстовых, коммерческих и семантических признаков;
- ML-оценка страницы с использованием `CatBoost`;
- расчёт конкурентного score с учётом top-N конкурентов;
- проверка соответствия страницы поисковому запросу;
- генерация рекомендаций с приоритетами;
- просмотр истории аудитов;
- просмотр таймлайна выполнения;
- экспорт отчёта по аудиту.

## Как работает аудит

1. Пользователь вводит URL проверяемой страницы и поисковый запрос.
2. Backend создаёт запись аудита в SQLite и ставит задачу в очередь `Celery`.
3. Pipeline загружает целевую страницу, сохраняет snapshot и извлекает признаки.
4. SearXNG получает страницы конкурентов по тому же запросу.
5. Конкуренты отправляются в отдельные задачи, поэтому несколько страниц могут анализироваться параллельно.
6. Для каждой страницы рассчитываются технические, текстовые, коммерческие и семантические признаки.
7. ML-модель оценивает качество страницы по набору признаков.
8. После анализа конкурентов система пересчитывает итоговый конкурентный score.
9. Recommendation layer сравнивает целевую страницу с конкурентами и показывает, какие факторы требуют доработки.
10. Пользователь получает обзор, сравнение конкурентов, рекомендации, таймлайн и отчёт.

Подробное описание этапов находится в [docs/AUDIT_WORKFLOW.md](docs/AUDIT_WORKFLOW.md).

## Быстрый запуск на Windows

1. Установите зависимости:

```powershell
npm install
npm --prefix frontend install
cd backend
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"
cd ..
```

2. Запустите Docker Desktop.

3. Запустите проект:

```powershell
npm start
```

После запуска откройте frontend в браузере:

```text
http://127.0.0.1:5173
```

Если используется готовый `.cmd`-файл, можно запустить `Start SEO Audit.cmd`.

## Быстрый запуск на macOS

1. Установите зависимости:

```bash
npm install
npm --prefix frontend install
cd backend
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"
cd ..
```

2. Запустите Docker Desktop.

3. Запустите проект:

```bash
chmod +x scripts/macos/start-site.sh scripts/macos/stop-site.sh
./scripts/macos/start-site.sh
```

Остановка:

```bash
./scripts/macos/stop-site.sh
```

Подробная инструкция для macOS находится в [docs/MACOS.md](docs/MACOS.md).

## Ручной запуск

Поднять Redis и SearXNG:

```bash
npm run searxng:up
npm run searxng:check
```

Запустить backend, frontend и Celery workers:

```bash
npm run dev -- --with-worker --worker-autoscale=auto
```

Порты по умолчанию:

- frontend: `http://127.0.0.1:5173`;
- backend API: `http://127.0.0.1:8000` или ближайший свободный порт;
- SearXNG: `http://127.0.0.1:8888`;
- Redis: `127.0.0.1:6379`.

## Как пользоваться сайтом

1. Откройте главную страницу.
2. Введите URL проверяемой страницы.
3. Введите поисковый запрос, по которому страница должна конкурировать.

8. При необходимости откройте историю аудитов или экспортируйте отчёт.

## Архитектура

Кратко:

- `React + TypeScript` отображает интерфейс и получает данные через HTTP API;
- `FastAPI` принимает запросы, хранит аудиты и отдаёт результаты;
- `SQLite` хранит аудиты, события, результаты и данные истории;
- `Redis` используется как брокер и backend результатов для Celery;
- `Celery workers` выполняют стадии аудита параллельно;
- `SearXNG` получает конкурентные страницы;
- `CatBoost` рассчитывает ML-оценку по признакам страницы.

Подробное описание архитектуры находится в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Частые проблемы

**Docker не запущен.**

Запустите Docker Desktop и повторите `npm run searxng:up`.

**Порт 5173 занят.**

Остановите старый frontend-процесс или задайте другой порт через `FRONTEND_PORT`.

**Backend не отвечает.**

Проверьте, что Python-зависимости установлены в `backend/.venv`, а Redis доступен на `127.0.0.1:6379`.

**Аудит долго выполняется.**

Некоторые страницы конкурентов медленно отвечают или блокируют загрузку. Состояние можно смотреть во вкладке таймлайна и на странице рабочего стека.
