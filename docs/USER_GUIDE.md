# Пользовательская инструкция

Документ описывает работу с интерфейсом SEO-аудита.

## Запуск аудита

1. Откройте сайт.
2. Введите URL страницы, которую нужно проверить.
3. Введите поисковый запрос.
4. Запустите аудит.

Система создаст задачу и начнёт анализ. Во время выполнения можно смотреть статус и этапы работы.

## Обзор результата

В обзоре отображаются:

- итоговый конкурентный score;
- оценка самой страницы;
- качество конкурентного контекста;
- количество обработанных конкурентов;
- основные сильные и слабые стороны.

Конкурентный score показывает не абстрактную оценку сайта, а положение страницы относительно конкурентов по конкретному запросу.

## Сравнение с конкурентами

Раздел сравнения показывает, как целевая страница выглядит на фоне страниц из поисковой выдачи. Это помогает понять, уступает ли страница конкурентам по техническим, текстовым, коммерческим или семантическим признакам.

Если часть конкурентов недоступна, система учитывает качество конкурентного контекста. Это важно, потому что неполные данные не должны выглядеть как полноценное сравнение.

## Рекомендации

Рекомендации сгруппированы по смысловым блокам:

- техническое SEO;
- коммерческие и trust-признаки;
- семантика и соответствие запросу;
- отставание от конкурентов.

Каждая рекомендация показывает, что именно стоит улучшить и почему это влияет на итоговый результат.

## Таймлайн

Таймлайн показывает ход выполнения аудита:

- запуск;
- загрузка страницы;
- анализ признаков;
- получение конкурентов;
- обработка конкурентов;
- расчёт score;
- формирование рекомендаций;
- завершение.

Таймлайн полезен, если аудит идёт дольше обычного: по нему видно, на какой стадии находится задача.

## История аудитов

История позволяет:

- открыть прошлый аудит;
- повторно запустить проверку;
- найти аудит по статусу, домену или запросу;
- скрыть локальную запись из списка без удаления backend-данных.

## Экспорт отчёта

После завершения аудита можно открыть отчёт и использовать его для передачи SEO-специалисту или заказчику. Отчёт содержит ключевые показатели, сравнение и рекомендации.
